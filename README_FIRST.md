# The Living Model — Codex website starter kit

Prepared for Saipranay Thandu. Goal: one production-grade local portfolio that presents Engineering + Analytics + Business through a fully interactive semantic architecture, backed by technically credible synthetic case studies.

## What to do in order
1. Read `LOCAL_RUNBOOK.md` and set up a fresh Next.js app in VS Code.
2. Copy `MASTER_CODEX_PROMPT.md`, `CONTENT_SOURCE.md`, and `AGENTS.md` into the new app root.
3. Install your Emil Kowalski, Impeccable and Taste skills in the project root using the Runbook's commands.
4. In Codex VS Code, paste the one-line activation prompt from the Runbook. Codex will read and execute the detailed Master Prompt locally.
5. Preview localhost and run the Runbook's 3 focused polish prompts.

## Included
- `MASTER_CODEX_PROMPT.md`: detailed end-to-end implementation specification, semantic architecture, UX, art direction, synthetic case studies, content and rigorous acceptance criteria.
- `CONTENT_SOURCE.md`: facts grounded in the three-page LinkedIn PDF and explicit added credentials; critical anti-fabrication guards.
- `AGENTS.md`: permanent project coding standards recognized by Codex.
- `LOCAL_RUNBOOK.md`: Mac / Node / VS Code setup, skill installations, prompt to paste, launch commands, design review passes, asset update workflow.

## Boundaries
This kit contains source-based content and instructions, not a website implementation or proof of test runs. Codex must create and test that implementation on your Mac.
The profile portrait and award evidence were not supplied. The build spec deliberately allows elegant fallbacks and hidden pending content. All example project data must be synthetic and labeled.
