# Portfolio application

The Next.js application for **Saipranay Thandu — Portfolio**, “Beyond the data.”

See the [repository README](../README.md) for the experience, architecture, setup, checks, and asset notices.

With Node.js 22+ installed, run from this directory:

```sh
npm ci
npm run dev
```

Production preview: `npm run build`, then `python3 -m http.server 3000 --directory out` (requires Python 3). GitHub Pages configuration and subpath details are in the root README.
